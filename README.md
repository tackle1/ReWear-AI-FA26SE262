# ReWear-AI-FA26SE262-
ReWear AI (FA26SE262) là nền tảng mua bán thời trang secondhand uy tín tại Việt Nam. Hệ thống tích hợp AI Computer Vision để tự động thẩm định hàng thật/giả và chấm điểm tình trạng sản phẩm qua ảnh chụp hướng dẫn. Kết hợp cùng thanh toán ký quỹ VietQR Escrow và quy trình phân xử tranh chấp minh bạch, bảo vệ tối đa người mua và người bán.
